# 首版架构与数据

## 决策

安卓原生 Java 客户端 + Python 3.11 及以上标准库 HTTP 服务 + SQLite。现有 Gradle Wrapper、JDK 17、SDK 36 可复用；不增加外部运行依赖。接口以 [api.md](api.md) 为唯一共享契约。

服务端是权限、版本、状态和时间的权威。客户端刷新与恢复前台时重新读取状态，不在断网时假装已提交。变更通过 requestId 去重与 expectedVersion 防止覆盖；业务状态、事件和请求回执在同一个数据库事务中提交。

## 身份与隔离

账号用唯一 handle、昵称与密码注册；密码按随机盐 PBKDF2-HMAC-SHA256 保存，不存明文。随机会话令牌只保存哈希，具备到期和退出撤销。服务默认绑定 127.0.0.1，本地调试通过 Android 模拟器宿主地址或 adb reverse 连接。生产必须通过 HTTPS 反向代理，调试的明文网络例外只允许 loopback 和模拟器宿主。

用户、关系、约定、图片、事件按权限过滤。成人成员 ID 等于账号 ID；孩子成员有独立 ID 与家长管理者，孩子不是伪造的登录账号。家长代记只在 proxy 关系允许，shared 关系禁止一人模拟两方确认。

## 存储实体

- users / sessions：账号与令牌摘要；密码、令牌不进入日志或导出。
- relationships：类型、模式、状态、成员、邀请凭证与有效期。共享关系最多两名成人；代记关系一名家长和一名孩子。
- agreements：稳定 ID、关系、双方成员 ID、任务与奖励状态、当前条款、进度、提交、奖励期限、待确认变更、版本。
- events：操作、操作者、代记来源、时间与必要的条款快照，不能被普通修改覆盖。
- media：上传者、类型与受限大小的图片；只能被上传者或关联约定的成员读取。
- receipts：actor + requestId 唯一，绑定请求内容；不同内容复用 ID 必须拒绝。

开发数据库位于 .local/pact/pact.sqlite3，不进入 Git；测试使用独立临时库。图片不放公开静态目录。会话只存应用私有偏好，不备份到系统云。

当前数据库格式使用 SQLite `PRAGMA user_version=1`。服务只接受未标版本的新库（0）与当前版本（1），初始化新库后写入版本；遇到其他版本会关闭连接并拒绝启动，不擅自改写。尚未实现未来格式之间的数据迁移；变更 Schema 时须另增有验证证据的迁移与恢复路径。

## 1.4.0 状态与记录兼容

自 1.4.0 起，新的 `give` 在原事务内直接将奖励由 `pending` 写为 `received`，保存真实 `give` 事件和幂等回执；`received` 的当前业务含义为兑现方标记已兑现。接收方二次确认被移除，任务达成与奖励兑现仍是独立字段。

旧库的 `offered` 在约定读取视图中映射为 `received`，不批量改写数据库，不递增版本或更改 `updatedAt`，不伪造 `receive` 事件。旧成功幂等回执保持原样，因此可能继续含 `offered`；Android 将其同样视为已兑现。新 requestId 的 `receive` / `dispute` 在原鉴权、成员与版本检查通过后返回 `409 retired_action`，旧成功请求仍可重放。数据库格式继续为 1，兼容与重启的回归入口见[测试指南](testing.md)。

代记来源按真实动作保留：家长代孩子接受、记录进度或提交的事件为 `proxy=true`；家长兑现自己的承诺时 `give` 的 actorId 为家长、`proxy=false`。约定的 `confirmationMode=proxy` 与孩子 ID 不变，不能据终态奖励标签抹去代记身份或宣称孩子独立确认。

客户端的单一“进度记录”由现有 `events` 派生，利用进度与提交事件内的快照展示次数、说明、照片、操作者及代记来源，不同时追加 `progress` 数组造成重复。旧说明、收讫和分歧事件保留原意；`comment` API 保留兼容，只有独立客户端入口退役。未新增时间线实体、响应字段或媒体公开路径。

## 构建与数据边界

应用身份为 `cn.zhiya.pact`，调试包为 `cn.zhiya.pact.preview`。公开仓库只包含当前约定产品；不包含其他应用的源码、用户数据或迁移工具。不自动清理已有设备或账号。

## 当前交付边界

开发服务可重启持久化，可由两台模拟器访问同一个数据库。不包括线上托管、找回密码、后台推送、高可用或自动备份服务；本地运行方式见[开发指南](development.md)，项目于 2026-09-30 暂停迭代。
