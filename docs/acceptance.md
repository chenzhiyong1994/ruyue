# 首版验收标准

PA-001 至 PA-009 是当前开发预览的稳定验收编号。每项结果须由对应程序检查或原生交互证明；历史验证不能自动替代新变更的回归。执行方法和已有验证边界见[测试指南](testing.md)。

| ID | 用户可见结果 | 必须证明 |
| --- | --- | --- |
| PA-001 | 两个账号建立关系 | 注册登录、邀请加入、自邀请/重复加入拒绝、第三人不能读取 |
| PA-002 | 提出并接受约定 | 全屏三步创建、返回步骤保留输入、最终确认前不写入；草稿私有、发布待接受、拒绝、角色互换、接受后生效 |
| PA-003 | 执行与验收 | 一次性/累计进度、文字与图片、补充重提、仅给予方可验收 |
| PA-004 | 达成与兑现分离 | 验收后待兑现、给出后待收讫、接受者收讫才完成、未收到不结清 |
| PA-005 | 条款协商 | 双方变更确认、确认前旧条款有效、版本冲突、历史快照保留；已提交后修改条件或次数需重新提交 |
| PA-006 | 到期与退出 | 按时提交不失效、超期不能默默补交、延期协商、解除不清除待兑现奖励 |
| PA-007 | 代记 | 家长可代记，所有事件和最终状态标明来源，普通关系不能代确认 |
| PA-008 | 可靠与私密 | 并发/重试不重复奖励、重启恢复、令牌撤销、媒体权限、断网不显示成功 |
| PA-009 | 安卓可操作 | 如约品牌及精致情感原生视觉；四页导航、关键按钮、状态下拉筛选、两端同步、大字体/窄屏、无旧课程资源；顶部无常驻关系栏或空同步占位，“我们”页按条件显示查看范围入口，应用后四页范围一致，返回取消不改范围，所选关系可辨认 |

## 程序验证

```powershell
python scripts/validate_project.py
python -m unittest discover -s tests -p 'test_*.py' -v
./scripts/android.ps1 -Offline
git diff --check
```

Windows 构建命令如上；macOS / Linux 使用 `sh android/gradlew -p android :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`。首次构建需下载依赖，尚未缓存时去掉 Windows 命令的 `-Offline`。原生验收见[测试指南](testing.md)，环境设置见[开发指南](development.md)。服务测试必须通过公开服务接口证明权限和状态，而非仅断言内部字段常量。HTTP 和设备测试使用专用数据库与预览应用包，拒绝清理已有用户或模拟器数据。

交付记录须列出实际命令、结果、APK、未验证项与已知限制。自动化、设备渲染、真实用户研究、线上验收分开报告。
